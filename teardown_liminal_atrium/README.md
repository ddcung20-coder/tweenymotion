# Liminal Atrium v3.34 — Teardown 샌드박스 맵

사진 속 보라빛 호텔 아트리움(리미널 스페이스)을 바탕으로 만든 Teardown 커스텀 맵입니다.

## 설치
1. 이 폴더(`Liminal Atrium`)를 통째로 `문서\Teardown\mods\` 안에 넣습니다.
   → `C:\Users\<사용자>\Documents\Teardown\mods\Liminal Atrium\main.xml` 이 되도록.
2. Teardown 실행 → **Mod Manager** → 왼쪽 *Local files* 에서 **Liminal Atrium** 선택 → **Play**.
3. 아트리움 남쪽에서 북쪽 벽을 바라보며 시작합니다 (사진과 같은 방향).

## 조작
- **문: 손으로 잡아당기거나 밀어서 엶** (물리 문, 경첩 2개로 벽에 고정). 문틀/벽을 부수면 경첩이 떨어져 문이 넘어짐.
  객실·욕실·계단·로비·정문 문 300개. 일부는 처음부터 열려 있음.
- **엘리베이터 4대**: 복도의 호출 버튼(문 오른쪽 빛나는 버튼)을 보고 E → 엘리베이터가 와서 "딩" 하고 문이 열림.
  카 안 버튼 패널(아래부터 1~6층)을 보고 E → 문이 닫히고 이동 후 문이 열림. 6초 뒤 자동으로 닫힘. 카는 물리 오브젝트라 타고 이동 가능.
- **도구**: 시작하면 기본 도구 전부 지급. 손에 든 무기는 매 프레임, 나머지는 0.5초마다 탄약 자동 보충
  (2.x 플레이어별 API·레지스트리 모두 사용). **K 키**: 탄약 진단 화면(현재 무기의 탄약 값 표시).
- **스폰 메뉴**: **N 키** 또는 ESC 메뉴의 **Liminal Spawn** → 자동차 3종, 짐 카트, 비치볼, 튜브, 킥보드, 나무 상자,
  드럼통, 소파, 구형 TV. (spawn.txt도 있어서 게임 기본 스폰 메뉴가 열리는 맵에서는 거기에도 나옴)
- **전등**: 전등마다 별도 조각(351개)이라, 그 전등을 맞히면 그 불만 꺼짐. 벽·다른 곳을 쏴도 다른 불은 유지.
- **문**: 문틀과 문짝 위아래 틈 5cm, 문 위쪽에 문막이 턱(닫으면 틈이 가려지고 반대쪽으로 안 넘어감).

- **객실 불 / TV (142개 객실 전부)**: 방 입구 옆(욕실 벽)의 **스위치**를 보고 **E** → 천장등·협탁 스탠드(트윈룸은 양쪽 2개 모두)·욕실등이 함께 켜지고 꺼짐.
  불 켜진 방은 커튼도 은은하게 빛나고, 끄면 같이 꺼짐. **TV 화면**을 보고 **E** → TV 켜기/끄기.
  처음 상태는 방마다 랜덤(불 켜진 방 / 어두운 방 / TV만 켜진 방). 총으로 깨뜨린 전등은 스위치를 켜도 안 켜짐
- **커튼**: 객실 창마다 커튼 2장. 커튼을 보고 **E** → 양쪽이 같이 스르륵 열리고/닫힘. 총 맞은 커튼 조각은 그 자리에 멈춤.

  - **레스토랑 LUMIERE**: 식탁보 테이블·촛불·의자, 바 카운터와 스툴, 와인 선반, 샹들리에
  - **CAFE**: 커피머신, 디저트 진열장, 컵 선반, 메뉴판, 테이블
  - 라운지 소파
  - **상가 음악**: 사용자가 준 노래(`snd/mall_song.ogg`)가 지하에 있을 때만 가장 가까운 스피커에서 반복 재생

  B1 계단실 벽에 빨간 "B1" 표시, 철문, EXIT 표시, 조명, 난간
- **엘리베이터 4대 모두 B1까지 운행** → 상가로 열림 (버튼 "Floor B1 (arcade)"). 층 표시등에 B1 칸 추가

## 헬기 / 헬리패드 (v3.28)
- 객실층 옥상 남쪽에서 **철제 계단**(노란 디딤판, 양쪽 난간)으로 한 층 더 높은 **아트리움 위 옥상**에 올라감
- 그 옥상에 **헬리패드**: 어두운 패드, 노란 원, 흰 H, 초록 가장자리 등, 풍향계, 투광등 2개, 옥상 둘레 난간
- **헬기** (직접 만든 고퀄 모델: 유리 캐노피·좌석·계기판·꼬리날개·스키드·항법등·착륙등)
  - 메인/꼬리 로터는 각각 축(조인트 2개)에 끼워진 별도 부품이라 떨어지지 않고 실제로 회전. 총으로 로터를 날리면 추락
  - 동체·날개는 플라스틱이라 총·폭발로 부서짐 (스키드·마스트·축만 금속). 크게 부서지거나 추락 충격으로 망가지면 엔진 폭발 + 화재
  - 다가가서 **E**로 탑승 → 로터가 서서히 돌기 시작 (헬기 소리)
  - **W/S** 앞/뒤, **A/D** 회전, **Space** 상승, **Ctrl** 하강, **E** 내리기. 화면 왼쪽 아래에 고도·속도·로터 표시
  - 입력이 없으면 제자리 호버링, 앞으로 갈 땐 기수가 숙여지고 회전할 땐 기울어짐. 방향은 실제 기수 방향을 따라감
  - 공중에서 내리면 천천히 내려앉음. 크게 부서지거나 로터가 떨어지면 ENGINE FAILURE → 그대로 추락
- 지도 남쪽(주차장 너머)에 **도로** 추가: 보도(주차장 진입로 2곳), 연석, 2차선 도로(노란 중앙선·흰 차선), 호텔 앞 횡단보도,
  맨홀·빗물받이, 가로등 5개, 가로수, 버스 정류장(BUS 표지판), 벽돌담+철제 펜스+산울타리, 양 끝 통행금지 바리케이드와 라바콘,
  길가에 주차된 기본 차량 밴 1대. 맵 경계도 도로까지 넓힘

## 미션: SWEET DREAMS (드림코어, 무섭지 않음)
1. 1층 로비 **프런트 데스크의 벨**을 보고 **E** → 꿈이 시작됨
   - 화면이 서서히 **파스텔 톤**으로 바뀌고(채도↓, 블룸↑, 분홍빛), 잔잔한 패드 음악이 깔림
2. **잃어버린 기억 6개**가 1~6층 객실 중 한 곳씩 **책상 위**에 분홍빛으로 빛나며 나타남 → 보고 **E**로 줍기
   - 주울 때마다 오르골 소리 + 그 층의 기억 한 줄 (예: "a soda from the vending machine at 3 a.m.")
   - 화면 위에 `MEMORIES n/6`, 남은 층 표시
3. 복도의 **파스텔 꿈꾸는 사람들(dreamer)** 은 층마다 2명. 그 층 기억이 있는 **방 문 앞까지 천천히 걸어가서 그쪽을 바라봄** → 길잡이
   - 옆을 지나가면 "흠~" 하는 소리와 함께 다정한 한마디 (사람마다 1번)
   - 쫓아오지 않고, 잡히는 것도, 화면이 어두워지는 것도 없음. 플레이어 쪽으로는 걸어오지 않음
4. 6개를 다 모아 벨을 다시 울리면 → **GOOD MORNING** — 화면이 부드러운 아침빛으로 밝아졌다가 원래대로 돌아옴
5. 벨을 다시 울리면 처음부터 다시 플레이 가능
- **미션 중단**: 미션 중 **M 키** 또는 ESC 메뉴의 **Stop Sweet Dreams** → 기억·꿈꾸는 사람이 사라지고 화면이 원래대로 돌아옴
- **꿈꾸는 사람(더미)은 미션 중에만 나타남.** 미션 전·중단 후·끝난 뒤(아침빛과 함께)에는 맵에 없음
- 미션 중에는 객실 창가·로비 구석·수영장에도 가만히 서 있는 파스텔 마네킹이 나타남
- 꿈꾸는 사람을 총으로 쏘면 그냥 넘어짐. 망가진 꿈꾸는 사람은 다음 미션에 다시 나오지 않음

- 건물 전체: 공조기·전기 웅웅거리는 리미널 앰비언스

- 수영장: 물결·물방울 소리(타일 방 울림), 스파 거품 소리
- 커튼 스르륵+고리 소리, 프런트 벨, 기억 줍는 오르골, 꿈꾸는 사람의 허밍, 아침 차임, 미션 중 파스텔 패드 음악
- **수영장 라디오**: 수영장 데크 사이드 테이블의 라디오에서 노래(`snd/radio_song.ogg`)가 반복 재생. 라디오를 쏘거나 부수면 멈춤.
- 수영장 물소리·스파·라디오 음악은 **수영장 안에서만** 들림 (연결 통로에서는 작게, 멀어질수록 서서히 작아짐)
  다른 노래로 바꾸기: `python3 tools/convert_song.py <노래.mp3>` (개인 사용 음원은 워크샵에 올리지 마세요)

## 구성 (1복셀 = 10cm, 약 680만 복셀, v2 고퀄리티)
- **아트리움** 16 × 27.2m, 높이 약 20m
  - 보라빛 벽(패널마다 미묘한 톤 차이, 이음매), 검은 창틀 + 가운데 창살이 있는 창 142개
  - 격자 천장 + 코브 조명 + 다운라이트, 몰딩, 바닥 환기구, 스프링클러
  - 12×12 석재 타일 바닥(줄눈), 2×2 짙은 러그(테두리 장식), 중앙 원형 메달리온
  - 케이블과 곤돌라, 화분, 벤치, **밀 수 있는 짐 카트**
- **객실 142개** (6층) — 방마다 랜덤
  - 더블/트윈, 좌우 반전 배치, 벽지 3색, 카펫 2색, 이불 3색, 정돈/흐트러진 침대
  - 커튼(불 켜짐/어두움, 열림/닫힘, 블라인드), 침대 위 그림, 협탁 스탠드·전화기
  - 책상·TV·미니바·전기포트·휴지통, 의자, 창가 안락의자+사이드 테이블, 라디에이터
  - 옷장(옷걸이, 가끔 코트), 짐 받침대 위 캐리어, 반쯤 열린 문, 스위치·온도조절기, 천장 감지기·환기구
  - 욕실: 타일 바닥·벽, 변기·휴지걸이, 워크인 샤워(트레이·턱·샤워기·커튼), 세면대+수전+거울, 수건, 발매트 (가운데에 설 공간)
- **복도**: 나무 징두리 + 체어레일 + 몰딩, 천장등·벽등, 소화기함, 스프링클러, 객실 번호판, 외벽 창(석재 인방),
  외벽 쪽에 액자·벤치·화분. **층마다 테마가 다름**:
  - 1층: 붉은 카펫 + 금색 메달리온, 크림 줄무늬 벽지
  - 2층: 레트로 주황 지그재그 카펫, 주황 벽지, **자판기 2대**
  - 3층: 초록 다이아몬드 카펫, 초록 벽지, **공중전화**
  - 4층: 파랑 줄무늬 카펫, 파랑 벽지, **벽에 그려진 가짜 문 + EXIT 표시**
  - 5층: 핑크/모브 물방울 카펫, 모브 벽지, **복도 끝 거울**
  - 6층: 차콜 카펫, 회색 벽지, 형광등이 자주 깜빡임, **버려진 청소 카트, 낡은 TV 카트, 벽을 보는 의자 하나**
- **계단실 2개**: 투톤 벽, 층 번호, 난간, 계단 논슬립, 열린 비상문, 옥상 펜트하우스
- **엘리베이터 4대**: 빈 샤프트(레일·케이블), 정지한 카(거울·나무벽·손잡이), 리넨실·하우스키핑 카트·제빙기
- **로비**: 파케이 바닥, 기둥, 프런트 데스크(모니터·벨), 열쇠 보관함, 소파, 샹들리에, 화분
- **외관**: 붉은 벽돌(엇갈림 쌓기), 석재 기단, 층마다 띠 장식, 코너 퀸(돌 장식), 코니스
- **실내 수영장 별관 (Poolrooms)**: 1층 북쪽 복도 → 유리 연결통로 계단 → 하늘색/흰색 타일 홀.
  12×7m 수영장(실제 물, 얕은 쪽/깊은 쪽, 레인 라인, 수중 조명, 사다리, 출발대), 원형 스파, 선베드, 안전요원 의자,
  탈의실 문, 시계, 음수대, 고창. 물에 뜨는 비치볼·튜브·킥보드(밀거나 쏘면 떠다님). 물소리·스파 거품 소리.
