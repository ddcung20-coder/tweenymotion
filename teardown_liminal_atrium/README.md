# Liminal Atrium — Teardown 샌드박스 맵

사진 속 보라빛 호텔 아트리움(리미널 스페이스)을 바탕으로 만든 Teardown 커스텀 맵입니다.

## 설치
1. 이 폴더(`Liminal Atrium`)를 통째로 `문서\Teardown\mods\` 안에 넣습니다.
   → `C:\Users\<사용자>\Documents\Teardown\mods\Liminal Atrium\main.xml` 이 되도록.
2. Teardown 실행 → **Mod Manager** → 왼쪽 *Local files* 에서 **Liminal Atrium** 선택 → **Play**.
3. 아트리움 남쪽에서 북쪽 벽을 바라보며 시작합니다 (사진과 같은 방향).

## 구성 (1복셀 = 10cm, 총 약 640만 복셀)
- **아트리움** 16 × 27.2m, 높이 약 20m: 보라빛 벽, 검은 창틀의 작은 창 142개, 격자 천장 + 코브 조명,
  돌바닥 + 2×2 짙은 러그 + 중앙 원형 메달리온, 천장에서 내려온 케이블과 곤돌라, 짐 카트, 벤치
- **객실 142개** (6층): 침대·베개·협탁·스탠드, 책상·TV·의자, 창가 안락의자, 라디에이터, 커튼,
  욕실(변기·욕조·거울·타일), 옷장, 열린 문 — 방마다 상태가 랜덤
  (불 켜짐+커튼 닫힘 / 불 켜짐+커튼 열림 / 어두움 / TV만 켜짐)
- **복도** (건물을 한 바퀴 도는 링): 붉은 카펫 + 금색 무늬, 천장등, 객실 번호판, 외벽 창
- **계단실 2개** (남서·동북 코너, 옥상까지), **엘리베이터 샤프트 4개** (북서·남동, 빈 샤프트 + 정지한 카),
  리넨·제빙기실
- **1층 로비**(프런트 데스크, 소파) + 정문 캐노피, **옥상**(공조기, 계단 펜트하우스), 주차장과 가로등
- 조명 264개, 대부분 복셀에 붙어 있어서 그 부분을 부수면 불이 꺼질 수 있음

## 재질 (부서지는 정도)
| 부분 | 재질 |
|---|---|
| 아트리움 벽·객실 벽·천장 | 석고(plaster), 잘 부서짐 |
| 바닥 슬래브·외벽·계단 | 콘크리트, 중간 |
| 가구 | 나무 / 플라스틱 |
| 창문 | 유리 |
| 창틀·문·난간 | 약한 금속 |
| 엘리베이터 레일 | 단단한 금속(heavy metal) |
| 맨 아래 지면 | 암반(rock), 파괴 불가 |

## 수정하기
`tools/build_map.py` 가 맵 전체를 생성합니다 (Python 3 + numpy).
층수(`FLOORS`), 방 개수(`LONG_BAYS`/`SHORT_BAYS`), 창 크기(`WIN_W`, `WIN_H`), 방 상태 비율(`STATES`) 등을
바꾼 뒤 `python3 tools/build_map.py` 를 실행하면 `vox/` 와 `main.xml` 이 다시 만들어집니다.
